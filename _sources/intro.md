# EK1225 Individual Practice Problems

This is a public, permanent home for EK125's per-class **Individual Practice
Problems (IPP)** -- the short, individual, in-class checks (not the group
GPP exercises), published as interactive [marimo](https://marimo.io) slide
decks that run live in your browser via WebAssembly (Pyodide). No server,
no sign-in, nothing to install.

Use the sidebar to pick a class. Each deck is one problem per slide, in the
same order as the original paper handout -- advance with the arrow keys or
the on-screen controls.

Every deck also has a 🚀 **Open in Colab** button in its top-right corner,
linking to the exact same content as a real, editable notebook, in case you
want to actually run any of the code snippets yourself.
